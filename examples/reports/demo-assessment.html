Method

Inventory is read from authorized AWS APIs and optional read-only host commands. Package versions are compared with Debian, RPM, or PEP 440 rules. A vendor or OSV range for the same ecosystem overrides an NVD upstream range, which is how backported fixes are represented. CISA KEV status is applied only from the loaded catalog. No exploit code is retrieved, and no system is patched by this report.
